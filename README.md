# Itesh's Portfolio 🚀

## Overview

A modern, fully SEO-optimized portfolio website built with **Next.js 16**, **React 19**, and **TypeScript**. Features interactive animations, dark theme, and a showcase of full-stack projects including AI/ML work.

**Live:** [iteshxt.me](https://iteshxt.me)

---

## 🎯 What's Inside

### Featured Projects

- **Dia Therapist** - AI-powered mental health assistant with custom fine-tuned LLM (Qwen 2.5 7B), voice I/O, and Flask backend
- **Sutr Clothing** - Full-stack e-commerce platform with Razorpay payments and Ekart logistics integration
- **Dia Moderator** - Multi-platform content moderation system (Discord, WhatsApp, Telegram) with Google Gemini AI
- **FitCheckr** - AI virtual try-on app using Google Gemini vision model for realistic clothing visualization

### Tech Stack

**Frontend:** Next.js 16, React 19, TypeScript, Tailwind CSS, Framer Motion, GSAP  
**Backend:** Node.js, Express, Flask, FastAPI  
**AI/ML:** Qwen LLM, PyTorch, HuggingFace Transformers, Google Gemini API  
**Databases:** MongoDB, Firebase, MySQL  
**Deployment:** Vercel, Railway, AWS
