# Portfolio v2 | Itesh Tomar

Welcome to the second iteration of my personal portfolio. This version represents a significant shift from a basic static site to a modern, dynamic **React-based** web application.

## ✨ What's New in v2?
Unlike the first version (v1) which was built with plain HTML/CSS, this version introduces a modular architecture and several premium features:

- **⚛️ Built with React & Vite**: Faster performance and component-based structure.
- **🌓 Dynamic Themes**: Full support for Dark and Light modes with smooth CSS transitions and local storage persistence.
- **🎨 Advanced UI/UX**: 
  - Custom typing animations on the landing page.
  - A themed "code-spinner" loading screen.
  - Responsive layouts for all screen sizes.
- **📧 Contact Integration**: Automated email delivery using **EmailJS**.
- **📂 Data-Driven**: Centralized `portfolioData.js` for easier content management.

## 🛠️ Tech Stack
- **Frontend**: React.js, Vite
- **Routing**: React Router DOM (v6)
- **Icons**: React Icons (Fa, Si)
- **Emailing**: EmailJS
- **Deployment**: Vercel / Netlify

## 📁 Project Structure
```text
src/
├── assets/      # Static assets (images, pdfs)
├── components/  # Reusable UI components (Navbar, Footer)
├── data/        # Centralized content (portfolioData.js)
├── pages/       # Page components (Home, Projects, Contact, Experience)
├── styles/      # CSS modules and theme variables
└── App.jsx      # Root component & Routing
```

## 🛠️ Getting Started
To run this project locally:

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
