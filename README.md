# Portfolio v2 | Itesh Singh

Welcome to the second major iteration of my personal portfolio. This version marks a transition from simple static pages to a fully dynamic, component-based **React** application.

## 🚀 Key Improvements in v2
This version introduces a modern architecture and several interactive features:

- **⚛️ Core Framework**: Built with **React** and **Vite** for a blazing-fast development experience and optimized production builds.
- **🌓 Advanced Theming**: 
  - support for **Dark and Light modes**.
  - Smooth theme transition animations.
  - Persistent theme settings stored in local storage.
- **🎨 Interactive UI**:
  - Custom typing animations on the landing page.
  - Themed loading screen with a custom "code-spinner".
  - Fully responsive design using custom CSS variables (theming engine).
- **📂 Performance-Oriented**:
  - Centralized data management via `portfolioData.js`.
  - Automatic scrolling to top on route change.
- **📧 Contact System**: Integrated with **EmailJS** for direct mailbox delivery.

## 🛠️ Technology Stack
- **Frontend**: React (v17), Vite (v2)
- **Styling**: Vanilla CSS with custom property variables (CSS-in-JS lite)
- **Navigation**: React Router DOM (v6)
- **Icons**: React Icons (Fa, Si)
- **Communication**: EmailJS / @emailjs/browser

## 📁 Repository Structure
```text
src/
├── components/  # Layout and modular UI parts (Navbar, Footer, ThemeToggle)
├── data/        # Central source of truth for all content
├── pages/       # High-level page components (Experience, Projects, etc.)
├── styles/      # Theme engine and global styling variables
├── App.jsx      # Main application entry and router setup
└── main.jsx     # Root rendering logic
```
